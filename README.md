# 國際重大事件對石油價格之影響
## 專案簡介
本人的第一個資料分析小專案。

此專案探討國際重大事件對石油價格的影響

石油價格以以下為研究變數:
- WTI歷代原油價格
- Brent歷代原油價格
## 為何選此主題做此專案
石油價格跟我們生活中所常見的物資的價格呈正關聯性，如:汽機車加油、塑膠袋
## 要分析什麼?
主要分析以下幾點:

1. 國際事件對石油價格的影響
2. 事件發生前與後的對比
3. 持續多久?
